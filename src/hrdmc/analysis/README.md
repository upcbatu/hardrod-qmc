# Analysis

Owner: comparison and uncertainty summaries.

This package owns blocking/error estimates, autocorrelation-aware time-series
diagnostics, mergeable streaming accumulators, QMC-versus-theory comparison
metrics, replicate-stability summaries, finite-size trends, bulk-versus-edge
diagnostics, chain stationarity diagnostics, failure maps, deterministic
density-envelope coarse graining, paired forward-walking observable
sensitivity, and time-step systematic fits. It does not own physical geometry
or solve LDA predictions.
