# Code units

The stored trapped-system convention is defined by
`src/hrdmc/system/units.py`:

- coordinate: `q = x/a_ho`
- energy coordinate: `E_tilde = E/(hbar*Omega)`
- dimensionless trap frequency: `HO_TRAP_OMEGA = 1.0`

These are the stored code conventions. The manuscript gives the physical
definitions and derivations.
